Lamplight Jazz Agent

Lamplight Jazz Agent is a private production tool used by the owner of the Lamplight Jazz YouTube channel.

It prepares long-form instrumental jazz videos (music, artwork, titles and descriptions), lets the channel owner review and approve every video, and then uploads the approved videos to the owner's own YouTube channel using the official YouTube Data API.

The tool is not offered to the public and does not access any other user's account.

YouTube API Services

This application uses YouTube API Services to upload videos and thumbnails to the owner's channel and to read the publication status of those videos. Use of the application is subject to the YouTube Terms of Service and the Google Privacy Policy.
